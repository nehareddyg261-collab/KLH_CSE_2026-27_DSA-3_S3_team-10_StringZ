# StringZ

Searches a word in a text file using the Normal (naive) method and the Z-Algorithm, then compares them.

## Run
Open the folder in VS Code and either:
- install the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**, or
- double-click `index.html` to open it in a browser.

No installation or internet connection is needed except for the Google Fonts (a fallback font is used offline).

## Structure
- `index.html` – page layout (Search and Compare tabs)
- `css/style.css` – light theme styles
- `js/algorithms.js` – `zSearch`, `naive`, `time`
- `js/app.js` – file reading, results table, comparison table and graph
